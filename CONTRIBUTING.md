# Contributing

## Commit messages

Short, emoji-prefixed, minimum words.

| Emoji | When |
|-------|------|
| ✨ | New feature |
| 🐛 | Bug fix |
| 🎨 | Visual / UX change |
| 😋 | UX improvement |
| 🚧 | Work in progress |
| ♻️ | Refactor |
| 🗑️ | Delete code / cleanup |
| 📦 | Dependency / config |
| 🔒 | Security |

**Good:**
```
✨ Add exercise correction API
🐛 Fix fn-run double-executing instructions
🎨 Right sidebar layout on exercise page
```

**Bad:**
```
feat: implement the correction endpoint — this was broken because...
fix: Fixed the bug where fn-run was double executing instructions and causing an error
```
